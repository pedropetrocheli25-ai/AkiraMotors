Mensajes WhatsApp

Configura los mensajes automáticos que se envían por WhatsApp. Usa las variables entre llaves para que se reemplacen con los datos reales del pedido.

Interruptor general

Si está desactivado, no se abrirá WhatsApp al cambiar el estado de un pedido.

M1 - Pedido en camino (al cliente)

Se envía al cliente cuando el pedido sale de la tienda.
Variables: {cliente}, {pedido}, {total}, {productos}, {empresa}

M2 - Asignación a domiciliario

Se envía al domiciliario cuando se le asigna un pedido. No incluye el total para proteger la información del negocio.
Variables: {cliente}, {telefono}, {pedido}, {productos}, {direccion}, {maps}, {empresa}

M3 - Pedido entregado (al cliente)

Se envía al cliente cuando el pedido se marca como entregado. Desactivado por defecto.
Variables: {cliente}, {pedido}, {total}, {productos}, {empresa}
